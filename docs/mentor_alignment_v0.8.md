# v0.8 原版对齐与交互说明

## 本次范围

保留五步问卷结构、共享生活史与体育暴露分流、博导二维绘图及三维几何。调整年龄/年级选择，恢复原版生活事件，接入原版教学，并改善页面呈现。正式心理量表与提交后台尚未接入。

## 原版生活事件与体育扩展

来源为用户提供的选项表 v2.1，只读保存在 `reference_notes/mentor-options.js`。原版 35 条负向、17 条正向题干、各自类别和类内顺序全部保留；展示按原版 `LT_DOMAIN_PAIRS` 的七组类别对照组织。当前采用固定源顺序，不额外随机排列或套用原项目数量及正负配额。体育 24 条追加为专项模块，不替换一般题目。

`mentor_neg_01` 等为稳定来源 ID；`aslec_bridge` 仅记录原作者的题目桥接标识，不代表完整 ASLEC 计分。原版参考严重度、归因权重与锁定默认答案不写入本研究自评字段，也不视为体育常模。

同类事件可点击“再次记录同类事件”。新增事件具有独立 ID、`occurrence`、首次回忆顺序、轨迹和情境；不会复制前一条的轨迹或评分。提示条目若对应多次记录，需在已选列表逐件管理，避免一取消勾选误删全部。同一件事在一般与体育两处出现，继续使用合并功能；不同时间的事件保持分开。

## 点击选择年龄与年级

年龄 16–35 周岁直接展开为数字单选格；年级展开为大一、大二、大三、大四、大五及以上、研究生。使用原生 radio 和 fieldset，支持鼠标、触屏与键盘。字段仍为 `profile.age` / `profile.year`，保持字符串格式，刷新后恢复选中态；年级未另加必答门槛。

## 原版画线教学

来源为用户提供的实验脚本 v3.6.3，快照为 `reference_notes/mentor-experiment.js`。保留原版虚构失恋示例、300×260 九宫格、绿色示范、当时中等→后来大→现在小的目标路径，以及一笔从下往上的序列判定。教学位于第三步内部，首次进入绘图时先练习，通过并点击继续后才进入自己的生命树。

- 示例不加入 `events`，不计入生活事件数量或体育暴露。
- `process.tutor` 保存已完成教学；`tutor_sessions` 分开记录重看、重试的各次会话及实际失败次数、路径和耗时。
- 刷新后已完成练习无需重做；绘图页可以“再看画线示范”，原有正式轨迹仍保留。
- 原版动作和判定保留；本地适配添加 Pointer 所有权检查、取消处理、失败后重试计时清理，以及离开/重看时清理全部定时器。
- 减少动画偏好下展示静态示范。键盘使用同一套路径判定：空格进入并落笔，方向键移动，Shift 微调，回车结束，Esc 清除当前一笔。
- 教学是绘图理解检查，不是认知访谈或心理测验。

可运行 `node questionnaire/prototype/adapt-mentor-catalog.cjs` 和 `node questionnaire/prototype/adapt-mentor-tutor.cjs` 从快照重建适配。参考快照中的问卷星交卷逻辑未加载到本问卷。

## 页面设计审查

按用户要求使用 `design-taste-frontend` skill。该 skill 主要面向展示页，本项目属于多步研究问卷，采用其保留现有结构的视觉审查方法；表单交互采用原生控件，未迁移框架或套用营销布局。

- 原有基础：浅色、绿紫语义色、生命树标识、五步流程、滑动推子和拖动排序。
- 当前方向：面向大学生的安静研究问卷，设计变化 3、动效 2、信息密度 4。统一浅色主题和灰绿色界面强调色；紫正 `#7B2D8B`、绿负 `#2D8B4A` 保持研究含义。
- 页面色板：底色 `#F1F5F2`、主文字 `#263C33`、辅助文字 `#596B62`、主操作 `#3F6251`。原生字体栈，无外部字体、营销图片或装饰动画。
- 层次：面板 16px、分组 12px、控件 8px；收敛标题字号、增加中文行高和选项间距，减少重复说明。选中态包含边框及文字变化，不能只靠颜色。
- 交互：年龄与年级大触控区域、可见焦点、固定原字段、清单折叠与已选计数、逐件排序和再次记录。情境题仍一题一行，保留立体推子。
- 手机：年龄五列、年级三列，清单和练习自动单列；主要操作最小 44px。页脚作为唯一浮动层（层级 10），绘图阶段使用画板自己的操作区。

## 旧草稿与验证

沿用原存储键，升级前 JSON 备份到 `sports-life-tree-prototype-v0.1-before-v0.8`。v0.7 已选的概括清单事件保留原 ID、原题干、轨迹和评分，标记 `legacy_catalog=true`；不假装它们是本次原版题目。旧有 `before-v0.7` 备份不变。v0.7 已明确自评的滑块不会重新变成 `legacy_unverified`。

运行 `npm test` 或 `pnpm test`。本轮验证包含：原版 52 条逐项一致性与类别对照、原版绘图/三维几何、整合分流、旧草稿迁移、年龄年级恢复、多次事件独立性、练习失败/重试/多指针/取消/键盘/减少动画、重看时计时器清理、实际页面脚本 DOM 流程及核心文字色板对比度。DOM 检查和对比度计算不等于真实浏览器视觉验证。桌面 UI 工具本轮无法连接，因此尚未重新进行浏览器、触屏和 WebGL 视觉检查。
