# 体育社会生态结构化代码本（SE1–SE7）v0.1

> 命名边界：博导项目 README 中的 **F7 是 `mid_kind`，表示转折类型**；社会生态相关字段是 F0、F3、F4 及其原始题目。本文的 `SE1–SE7` 是本项目新建的体育社会生态模块，避免与博导项目的 F7 冲突。

F7 只对受试者选出的 1–2 件关键体育事件完整填写。每个事件保存原始答案和派生编码。

| 变量 | 题目 | 建议回答 |
|---|---|---|
| `f7_where` | 主要发生在哪里？ | 训练场、比赛场、家庭/宿舍、学校管理场景、线上、多个场景、说不清、不愿回答 |
| `f7_who_all` | 主要和谁有关？ | 可多选：主教练、助教、队友、对手、裁判/组织者、家人、同学/朋友、学校/俱乐部管理者、自己、其他 |
| `f7_who_primary` | 其中最关键的是谁？ | 单选 |
| `f7_closeness` | 和关键人物当时有多亲近或信任？ | 0–10；另设说不清/不愿回答 |
| `f7_why_primary` | 这件事主要因为什么？ | 训练/表现、教练反馈、队友支持/冲突、对手/裁判、选拔/排名、伤病、器材/场地/经费/机会、家庭/学业、偶然机会 |
| `f7_why_secondary` | 是否还有次要原因？ | 可选单选 |
| `f7_control` | 对这件事有多大控制感？ | 0=完全无法控制，10=完全可以控制 |
| `f7_autonomy` | 训练或比赛决策有多大自主权？ | 0=完全由别人决定，10=主要由自己决定 |
| `f7_resource_fairness` | 获得的资源和机会有多公平、充足？ | 0=非常不公平/不足，10=非常公平/充足 |
| `f7_outcome` | 后来怎么样了？ | 持续变好、回落、保持、一直困难、有人帮助后改善、伤病/落选中断、后来失去、说不清、不愿回答 |
| `f7_turn_age` | 若有转折，大约何时发生？ | 年龄或年级 |
| `f7_turn_impact` | 转折时影响有多大？ | 0–10 |
| `f7_refuse` | 是否拒答或不适？ | 0/1；不参与主分析的中间值编码 |

## 跳转规则

- `f7_closeness` 仅在选择具体关键人物后出现。
- `f7_turn_age` 和 `f7_turn_impact` 仅在选择转折类后续结果后出现。
- 连续滑竿不预填，实际拖动后才写入。
- “说不清”和“不愿回答”保留为独立类别，不自动编码为 0.5。
