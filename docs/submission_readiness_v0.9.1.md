# v0.9.1 博导审阅前准备清单

这份清单用于区分“可以展示的交互原型”和“还不能声称完成的正式研究”。当前版本适合提交设计、逻辑和实现审阅，不适合直接作为正式受试者数据收集版本。

## 现在已经落地

- 研究对象与设计：大学生总体，允许体育专业和校队／竞技训练学生重叠；采用横断面关联研究表述。
- 事件框架：博导原版 52 条一般生活事件 + 24 条体育专项事件；正负经历并列，支持自填、重复记录、合并和纵向拖动排序。
- 分流逻辑：体育专业、队伍身份、比赛、专项训练、获奖分别记录；体育课／日常运动不自动算作专项训练；比赛但未获奖保留。
- 生命树：原版示范、九宫格练习、自由绘线、撤销／重画、二维有符号轨迹和三维查看器均可运行。
- 映射：F0–F20 与社会生态字段由同一映射函数生成；三维图中新增图形只用于解释字段位置，不改原版几何。
- 数据边界：只读本地 localStorage 和 JSON 导出；仓库不保存真实作答数据，3D 演示使用明示模拟经历。
- 验证：模型、目录、迁移、映射、DOM 流程和三维桥接测试均纳入 `npm test`。

## 提交时必须主动说明

1. 这是“生活史交互原型／工具开发基础版”，不是已经验证的正式量表。
2. 当前 `outcome_scales_status=not_integrated`：心理韧性、焦虑、抑郁量表尚未接入，也没有个体诊断或反馈。
3. 三维扇角、环弧、双环、转折菱形、持续状态框、底座环和当前影响光环是可视化编码，不是新增心理测量维度；F0–F20 也不是 21 个三维几何轴。
4. 横断面只能报告关联和统计解释，不能把“体育经历对心理健康的影响”写成已证实的因果结论。
5. “没有比赛／没有专项训练”只表示背景暴露回答，不等于没有日常身体活动；有比赛但未获奖也不能与没有比赛混为一组。

## 正式发放前必须补齐

- 伦理审批、研究说明、知情同意、退出权和敏感经历提示。
- 焦虑、抑郁、心理韧性量表的中文版本、授权、计分规则和缺失处理。
- 问卷星或等价安全后台、匿名 ID、数据字典、访问权限、备份和删除流程。
- 学校心理中心／危机支持资源文案，以及高风险回答的转介规则。
- 预计作答时间、手机端真实浏览器复查、负担与完成率评估。
- 专家内容评审和小样本试填；若声称优于 CTQ／ASLEC，需要预先定义对照工具与效度指标。
- 统计分析计划：四类体育暴露、获奖与未获奖的比较，混杂变量，缺失处理，以及中介／调节模型的前提和限制。
