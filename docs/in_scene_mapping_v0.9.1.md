# v0.9.1：三维树中的映射与直接点选

用户要求将映射直接描绘在三维图中。本版在博导原版轨迹几何上增加独立的图形层；沿用上一版 F0–F20 字段转换，原始轨迹、原答与字段含义保留。

## 图中怎么读

| 维度 | 三维场景中的标记 | 数据来源 |
| --- | --- | --- |
| 中心性 | 地面的角度弧与刻线 | F18，继续按原版角度规则；F1 缺失、使用条目权重后备时明确标注 |
| 归因可控 | 轨迹上的环弧，填充角度为码值×整圆 | F2 原版归因字典码 |
| 人际 | 轨迹上的内／外双环弧，分别表示关系类别码和亲疏评分 | F3／F4；未答的通道不画 |
| 转折与持续 | 真实转折年龄／影响位置的菱形，大小随转折码变化；末端状态框虚线表示仍持续，实线表示非持续，持续性未知时仅画淡框 | F5–F9；菱形离开原路径时用虚线连接同年龄的路径位置 |
| 条目参考 | 起点在地面的投影旁增加底座环，半径随参考权重变化 | F11／F12；体育新增、自填或多原条目合并无适用权重时不画 |
| 当前影响 | 末端光环半径随当前显著性增大，达到焦点阈值时加第二环 | F17／F19；F13–F16 仍通过原有轨迹半径和年龄展示，F10／F20 仍对应起终影响变化 |
| 生活场景 | 起点的六角标和地点／生态码文字 | F0；用类别文字说明，不把地点解释为心理分数 |

归因码、关系类别码与条目权重沿用博导提供的版本。附加环弧等是本项目的新可视化表达，尚未作为经过验证的心理测量指标。所有图形均有最小可见尺寸；标签显示真实值，空值不会变成默认半分。

角度弧只显示当前选中经历的一条，避免重叠。图形上附有当前经历的投影引线和标签，随相机旋转更新；图底常驻图例。点击轨迹切换标记和父页面字段面板，详细注释通过“字段详情”按钮打开。

图内“映射：开／关”切换附加图层，“标记：全部／选中”控制显示范围。超过 6 条经历时初始只显示选中经历的附加标记；原版全部轨迹仍显示。关闭映射后不可拾取隐藏标记。切换立体／地面视图会按相同映射规则重建，不累积图形资源。

## 情境题直接选择

情境页全部原下拉选项改为展开的原生 radio 按钮块，包括地点所属场景、关键人物、人物关系类别、归因类别，以及条件适用的体育阶段／比赛层级／结果／获奖层级／伤病。可以直接点击、触屏选择或使用键盘。每组提供“暂不填写”以清空答案，原有已选答案自动恢复。原有多选人物芯片和评分滑块继续使用。

本次不改变事件字段结构，发布版本统一为 v0.9.1。已有 v0.7／v0.8／v0.9 草稿由模型迁移到 v0.9.1；迁移只更新版本和缺失字段，不把 v0.9 已确认评分重新标为 `legacy_unverified`。模拟三维演示同步加入明确标注的跨轴康复示例，便于查看转折菱形；不读取参与者草稿。

三维新增符号是解释层的图形编码：它们帮助审阅者在图中定位 F0–F20 和社会生态字段，不能被解释为新增量表、常模或因果模型。半径仍表示影响强度，竖向仍表示年龄，原版轨迹和二维有符号路径仍是主要数据记录。

## 实现与验证

`mapping-scene.mjs` 构造独立 Three.js 图层、投影标签、图例与控制器，由 `adapt-mentor-3d.cjs` 接入原版查看器。原版核心几何函数逐段保留检查继续通过。`serve.cjs` 增加 `.mjs` 的 JavaScript 响应类型；本地服务已重启以加载该配置。

运行 `pnpm test`。新增验证使用真实 Three.js 对象核对几何位置、环弧值、参考半径、焦点双环、零／缺失区别、显示范围、标签边界和资源释放；还执行生成查看器的实际脚本和数据握手，检查绘图、选中、详情按钮与地面视图切换。该脚本测试替代绘制器与 OrbitControls，不等于真实 WebGL 或浏览器视觉验证。情境页流程检查确认无下拉框、单选互斥与清空答案。

桌面 computer-use 本轮仍返回 `Computer Use native pipe is unavailable ... 系统找不到指定的文件`，未完成浏览器截图和触屏视觉复查。
