# 生活史工具验证计划 v0.1

## 研究问题

新工具是否比 CTQ/ASLEC 类静态经历测量提供更丰富、更完整且更可用的生活史信息？

## 四个“更好”维度

1. **覆盖更完整：** 正向/负向事件类别、体育事件类别、开放式补充率。
2. **信息更丰富：** 时间、当时影响、现在影响、变化方向、当前显著性和社会情境字段的完整度。
3. **测量更可靠：** 重测一致性、事件顺序稳定性、核心滑竿重复性和逻辑一致性。
4. **体验更好：** 完成率、退出率、完成时间、操作错误、主观负担、理解度和可接受性。

## 推荐流程

- 专家评审：检查正负事件覆盖和体育事件遗漏；
- 认知访谈：观察受试者如何理解“当时/现在”“中心性/影响”“主要人物/主要原因”；
- 小样本试填：记录每一幕耗时、退出点、缺失和首个回忆事件；
- 重测子样本：间隔约 1–2 周，检验核心事件和轨迹字段稳定性；
- 正式调查：比较新工具与 CTQ/ASLEC 的覆盖、关联和增量信息。

## 首个回忆效应

保留 `select_order`，同时检验第一件被回忆的事件是否在 `centrality`、`r_now`、`now_salience` 上系统性偏高。若存在首项放大，应在论文中作为记忆提取顺序效应报告，而不是把第一件事件直接当作真实最重要事件。

## 结论边界

只有在覆盖、效度、可靠性和体验至少有多项证据支持时，才使用“优于”或“更好”；否则使用“提供了不同类型的信息”或“具有增量信息”。
