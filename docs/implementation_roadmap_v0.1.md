# 体育生活史工具与横断面研究落地规划 v0.1

此处保留最初规划。当前交互、一般生活与体育共同树的分流及导出字段以 [v0.7 整合方案](common_life_history_v0.7.md) 为准；旧版仅体育事件的限制已调整。

## 一、最终交付物

本项目最终交付两个相互连接但不能混为一谈的成果：

1. **生活史评估工具：** 记录正向/负向体育经历的类型、时间、当时影响、现在影响、变化轨迹和社会情境，并验证覆盖、可靠性和作答体验。
2. **体育应用研究：** 在大学生横断面样本中分析训练经历、比赛获奖经历与心理韧性、焦虑和抑郁的关联，并探索自我调节、情绪调节、心理韧性和孤独感的中介/调节作用。

## 二、研究范围冻结

### 研究对象

- 当前在读大学生；
- `pe_major`：是否体育专业；
- `team_athlete`：是否校队、运动队或竞技训练；
- 两个身份可以重叠；
- 其他学生也可以参加，不要求有获奖经历。

### 设计

- 横断面调查；
- 主要结论使用“关联”“增量信息”和“探索性机制”；
- 不使用“导致”“影响”作为横断面因果结论。

### 核心结果

- 主要心理结果：焦虑、抑郁；
- 核心心理机制：心理韧性；
- 自我调节、情绪调节和孤独感作为次要中介/调节变量；
- 睡眠、伤病、既往心理帮助和社会经济状况作为协变量。

## 三、12 周执行路线

### 第 1 周：研究问题与变量冻结

产物：

- 一页研究问题与假设；
- 一张 DAG；
- 人级、事件级、过程级变量清单；
- `pe_major`、`team_athlete`、训练暴露、获奖暴露和心理结局的操作定义。

门槛：每个主要变量都能回答“来源是什么、测量时间窗是什么、进入哪个模型”。

### 第 2 周：正负事件清单和体育事件词典

产物：

- 正向事件清单；
- 负向事件清单；
- 体育训练、比赛、获奖、伤病、落选和队伍变化条目；
- 每个条目的领域、正负性、是否可重复发生和是否需要预填。

动作：

- 邀请博导/核心专家先评审正负性完整性；
- 对每一类事件建立“清单条目—开放式补充—研究变量”的映射；
- 不先给自填事件赋予看似客观的严重度结论。

门槛：专家能够指出遗漏条目，且清单不会诱导受试者只能回忆负面事件。

### 第 3 周：工具验证方案与问卷代码本

产物：

- `tool_validation_plan_v0.1.md` 修订版；
- `SE1–SE7` 体育社会生态代码本；
- 事件级 JSON 结构；
- 人级数据表、事件级数据表、过程质控表。

推荐数据表：

| 表 | 一行代表什么 | 关键内容 |
|---|---|---|
| `person` | 一名受试者 | 人口学、体育身份、协变量 |
| `event` | 一件经历 | 事件类型、领域、正负性、时间、顺序 |
| `trajectory` | 一条事件轨迹 | `r_then`、`r_now`、`age_*`、`path_ar` |
| `social_context` | 一件事件的社会情境 | `where`、`who`、`why`、`how`、`SE1–SE7` |
| `scales` | 一名受试者的量表 | 韧性、焦虑、抑郁、自我调节等 |
| `process` | 一次作答过程 | 时长、退出、练习成功、缺失、努力程度 |

门槛：所有变量有唯一名称、取值范围、缺失代码和计分规则。

### 第 4 周：认知访谈

样本：8–12 名大学生，覆盖普通学生、体育专业和校队/竞技训练学生。

重点观察：

- 是否理解“当时影响”和“现在影响”的区别；
- 是否理解“中心性”不等于“影响大小”；
- 正向和负向事件是否都能被回忆；
- 首个回忆事件是否被认为是“最重要事件”；
- “主要人物”“主要原因”“后来结果”是否能稳定回答；
- 画线任务是否比普通量表更容易完成，还是增加了负担。

产物：逐题问题清单、修改记录、保留/删除理由。

门槛：没有连续出现的术语误解；关键字段能够被受试者用自己的话解释。

### 第 5 周：纸笔/静态页面小试

样本：30–50 名大学生。

记录：

- 总完成时间和各幕时间；
- 练习成功率；
- 事件选择数量；
- 核心字段缺失率；
- 首个回忆事件与后续事件的差异；
- 退出点和不适反馈；
- 主观负担和可理解性。

建议目标：核心题缺失率低于 5%，中位完成时间控制在 15–20 分钟内；若达不到，先减负，不直接进入正式调查。

### 第 6 周：体育版交互实现

实现顺序：

1. 年龄/年级和基本背景；
2. 体育事件清单；
3. 早→晚排序与 `select_order`；
4. 轨迹绘制与 `path_ar`；
5. 所有事件的核心标签；
6. 条件性转折和社会生态深描；
7. 量表、体验反馈和脱敏导出。

原则：全局事件矩阵保留全部已选事件的核心维度；深描模块可以条件展开，但不能替代全局记录。

### 第 7 周：技术质控和安全检查

检查：

- 手机端显示和触控；
- 返回、重画、删除、补画和断点续答；
- 负向绿色/正向紫色在所有页面一致；
- `select_order`、`age_*`、`path_ar`、事件 ID 是否稳定；
- 自填事件是否能正常导出；
- 邮箱是否与主数据分离；
- 退出后敏感回答的保存和删除逻辑是否与说明一致。

门槛：不出现重复事件、顺序错乱、无轨迹事件或无法解释的默认滑竿值。

### 第 8 周：正式调查前预注册与样本计划

冻结：

- 主暴露；
- 主结局；
- 主要中介；
- 协变量；
- 缺失处理；
- 排除规则；
- 多重比较方法；
- 主要图表和模型。

样本初步规划：总样本约 500–800 人；四个身份组合单元尽量都有足够样本。最终样本量需根据主模型、交互项和预期效应量进行 power analysis。

### 第 9–10 周：正式收集

收集期间每天检查：

- 完成率和退出率；
- 各身份组合数量；
- 手机/浏览器异常；
- 极短作答和练习失败；
- 正负事件清单是否出现明显偏斜；
- 事件字段缺失和逻辑冲突。

不能根据中途结果临时改变主假设或主要结局；需要修改时记录版本和理由。

### 第 11 周：数据冻结与分析

分析顺序：

1. 质控和缺失模式；
2. 正负事件覆盖与时间轨迹描述；
3. 新工具与 CTQ/ASLEC 类量表的覆盖和增量信息比较；
4. 训练/获奖与心理韧性、焦虑、抑郁的主关联；
5. 心理韧性的探索性间接效应；
6. 自我调节、情绪调节和孤独感的次要模型；
7. `select_order` 的首个回忆效应；
8. 身份交互：训练量 × `pe_major`、训练量 × `team_athlete`。

### 第 12 周：结果与论文结构

论文结果至少包含：

- 工具流程和测量结构；
- 正负经历覆盖情况；
- 轨迹数据和作答体验；
- 体育暴露与心理结局的关联；
- 中介/调节的探索性结果；
- 横断面设计的因果边界和工具局限。

## 四、正式问卷的最小版本

### 必留

- 体育专业和校队身份；
- 训练年限、近期训练频次和时长；
- 获奖层级、次数、最近性和主观重要性；
- 事件清单、时间轨迹和正负性；
- 每个事件的核心标签；
- CD-RISC-10；
- PHQ-9 + GAD-7，或基础版 PHQ-4；
- 睡眠、伤病、既往心理帮助；
- 完成时间、退出和努力程度。

### 可后置

- 多折点轨迹；
- 复杂 3D 可视化；
- 大量开放式文本；
- 过多的次要中介量表；
- 与正式研究问题无关的功能反馈。

## 五、三条不可违反的研究规则

1. 先验证工具是否提供增量信息，再解释体育经历与心理结局的关系。
2. 全局记录所有事件，不能只用第一件回忆或单个焦点事件代表完整生活史。
3. 横断面结果只做关联和探索性机制解释，不写因果影响。
