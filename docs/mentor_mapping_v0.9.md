# v0.9：清单展开与博导六类映射

## 修正内容

经历页所有适用类别直接展开，采用普通 section，不再采用折叠控件。保留原版七组类别、题干和顺序，左右分别显示不好的事／好事；体育扩展同样展开，原有适用条件保留。

之前的三维桥接只有轨迹和部分原答，没有完成原答至 F0–F20 的转换。现在结果页常驻六类映射，所有 21 个字段均可见，并与三维注释使用同一份映射数据。选中三维轨迹会切换面板，选择面板中的经历也会选中三维轨迹。初始不自动打开遮挡画面的三维注释框。

## 映射来源

字典与转换直接取自用户提供的选项表 v2.1，快照为 `reference_notes/mentor-options.js`。运行 `node questionnaire/prototype/adapt-mentor-reference.cjs` 可重建隔离的参考模块；原始快照不修改、不直接作为全局脚本加载。

| 类别 | 字段及依据 |
| --- | --- |
| 事件中心性 | F1 本人评分；F18 角度优先用中心性，其次原版条目参考权重 |
| 归因与可控 | F2 按正负效价使用原版 Q3 字典 |
| 人际 | F3 关键人物关系类别；F4 与该人物的亲近／信任评分 |

原版三维几何保持不变。不是将每个构念都硬编码成新的几何轴；博导原版的六类注释被接通，并在父页面直接展开。半径表示影响、竖向表示年龄、角度按上述规则展开；紫色为正向、绿色为负向。三维保留原版影响绝对值及半区展示，跨轴方向仍见二维与原始有符号轨迹。黄色合成箭杆和 +1 年外推仅是原版几何示意。

## 补充题与缺失处理

- Q1 恢复家里、宿舍、学校、网上等原版选项；Q3／Q4 按正负效价恢复原版选项。旧版原答仍显示、保存，不自动改成某个新类别。
- 训练场／比赛场及旧版歧义地点由本人补选 `where_basis`。新增体育归因由本人补选 `why_basis`。
- Q2 保留可多选；多人时增加 `who_primary`，不自动使用第一个人或平均关系码。教练、队友等新增角色通过 `who_tie_basis` 补选原版上位类别。切换关键人物时，旧亲疏评分和关系类别存入 `context_change_history`，当前亲疏评分重新作答。
- Q4 的特定转折选项才展开转折年龄与影响滑块，一题一行；未操作不写入视觉默认值。年龄限制在该轨迹起止点之间。
- 与原版一致，轨迹跨轴时按方向带入“后来变好了／后来失去了”。转折年龄和影响优先采用原绘图核心保存的 `age_cross`／`r_cross`，缺失时使用保留轨迹中的跨轴点；来源分别记录为 `original_crossing_sample`／`path_crossing`。不以起终点差编造中间点。本人调整后来源为 `self_report`。
- F19 未作答为 null，真实低评分为 false；0 分、false、不适用和缺失分别处理。原始 `age_end:null` 保持为空，不伪装成确定的结束年龄。
- 体育新增、自填事件无原版参考权重，保留 null。同类事件独立重复时复用来源条目参考；合并涉及多个原版条目时不取平均或任取其一。只有单一明确原来源的合并才显示该来源的参考权重。

字典码和参考权重沿用博导提供的版本，不宣称是本体育样本的已验证常模。其缺失不阻止完成问卷。

## 数据与升级

导出 `events[].mapping` 包含 `fields`、`sources`、`missing_fields` 与规则后的 `how`；`details` 为条件适用的原答字段，`details_raw` 保留全部原答及变更历史。三维桥接也调用同一个映射函数。视图筛选不改变导出范围或原始记录。

继续沿用原草稿键。升级前备份为 `sports-life-tree-prototype-v0.1-before-v0.9`；已有 v0.7／v0.8 的合法自评不会因升级被标成来源不明。早期来源不明评分仍须重新确认。

模拟演示同步接入六类映射，仅使用明示模拟数据，不读取问卷草稿。正式心理量表和收集后台仍未接入。
