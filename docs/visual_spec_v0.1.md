# 视觉规范 v0.1

当前页面的色板、交互和响应式规则见 [Unslop 界面精修记录](unslop_design_review.md)；早期设计依据见 [v0.8 页面设计审查](mentor_alignment_v0.8.md#页面设计审查)。以下正负颜色含义保持不变。

- 正向经历：紫色 `#7B2D8B`
- 负向经历：绿色 `#2D8B4A`
- 负向绿色保持冷色调、低饱和背景和较高文字对比度
- 不用红色表达负向经历，避免把“负向经历”误读为警报或错误
- 正负颜色在所有页面、轨迹、图例、导出图和统计图中保持一致
- 颜色只表示 valence，不表示影响大小；影响大小用线宽、半径或明度编码
- 事件标签文字必须同时显示“好事/不好的事”语义，不能只依赖颜色
