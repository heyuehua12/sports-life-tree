# 研究版本记录

## v0.1（基础版）

- 建立独立项目目录
- 将博导项目的流程抽象为：事件选择 → 时间轨迹 → 结构化社会生态 → 心理结果
- 体育事件改为：获奖事件、训练阶段、训练转折
- F7 初步定义为七个维度：场景、关键关系、关系质量、作用机制、控制感与自主权、资源公平、后续轨迹
- 计划使用 CD-RISC-10 与 PHQ-4；正式发放前需核对中文版本、授权和伦理要求
- 研究对象冻结为大学生总体；体育专业身份与校队身份分别编码，允许重叠
- 研究设计冻结为横断面；论文中使用关联和探索性机制表述

## v0.2（研究定位修订）

- 将项目定位调整为“生活史工具开发验证 + 体育经历应用研究”
- 采用全局事件矩阵：所有已选事件保留同一组核心维度
- 保留 `select_order`，把首个回忆效应作为可检验的顺序效应
- 将体育社会生态命名为 `SE1–SE7`，不与博导项目的 F7=`mid_kind` 混用
- 增加 CTQ/ASLEC 类测量的内容覆盖、信息丰富度、可靠性和作答体验验证计划
- 视觉规范冻结为正向紫色、负向冷绿色

## v0.3（直接交互实现）

- 跳过认知访谈，先实现可运行的本地原型
- 完成背景、事件清单、轨迹、全局情境标签和 JSON 导出流程
- 所有已选事件保留统一核心字段
- 正式量表暂不复制到原型，保留接入接口

## v0.4（自由绘制生命树）

- 将轨迹预览改为 SVG pointer 事件自由绘制
- 从“当时”向“现在”拖动，禁止年龄方向倒退
- 保存有符号 `path_ar`，记录 `r_then`、`r_now`、`cross_axis` 和 `impact_delta`
- 支持清空重画、撤销上一笔和事件间切换
- 使用真实屏幕坐标映射修复画布缩放偏移；终点必须达到“现在”才保存
- 补充全局淡显、年龄刻度、多次跨轴检测、最多 32 点弧长采样和撤销恢复
- 完成几何单元验证及桌面/手机浏览器流程检查

## v0.7（共同生活史与体育经历整合）

- 所有学生开放一般生活史；体育专项清单按实际暴露展开，日常运动单独标注。
- 加入多领域标签、体育关系确认、同一事件合并与完整原始记录归档。
- 保留博导绘图核心，在共同二维/三维结果中按关系和领域筛选。
- 全部事件回答共同核心题，训练、比赛与伤病题按适用条件展开。
- 新增训练量和比赛层级背景接口，规范区分缺失、不适用和真实零。
- 旧草稿升级前备份，轨迹不变，旧评分来源不明时保留原值并等待确认。
- 规范说明见 `common_life_history_v0.7.md`；新增模型与实际页面 DOM 流程自动化验证。

## v0.8（博导原版清单、示范练习与问卷呈现）

- 年龄 16–35 岁、年级均直接展开为原生单选项，点击选择并保存。
- 一般生活清单恢复博导提供的原版 35 条负向、17 条正向题干、分类、类内顺序和类别对照，另加体育专项 24 条。
- 支持同类事件多次记录，每次有独立 ID、回忆顺序、轨迹和情境。
- 接入原版示范动画与九宫格一笔练习，通过后进入正式绘图；支持重看、失败重试、键盘和减少动画，离开时清理计时器。
- 统一柔和页面配色、可见选中态、字号、间距、手机布局及键盘焦点；紫正绿负与原绘图核心保持。
- 升级前备份，旧 v0.7 题干及轨迹原样保留，已确认评分不重新降为来源不明。
- 模型、清单逐项一致性、DOM 流程、练习分支与文字配色对比度测试通过；本轮未重新进行真实浏览器视觉检查。
