这是一个独立于博导项目的本地研究项目。博导项目只作为交互流程、事件时间线和社会生态结构化的参考，不直接修改其仓库，也不复制其研究数据。

## 研究对象与设计

研究对象是普通大学生总体，其中包含体育专业学生和校队/竞技训练学生。体育专业身份与校队身份可能重叠，因此主分析分别保存为两个二元变量，而不是强行划成三个互斥群体。

本研究采用横断面调查。正式表述使用“关联”“统计解释”或“可能机制”，不使用“导致”或“影响”。

## 本项目的科学定位

本项目首先是一个生活史评估工具开发与验证研究，其次才是体育经历与心理结局的应用研究。目标不是简单增加一张体育问卷，而是形成一个比 CTQ 类静态经历量表更丰富的生活史评估工具：

- 保留事件发生的时间和影响轨迹，而不只记录“有没有发生过”；
- 同时覆盖正向和负向经历，正负性完整性需要通过专家意见、内容覆盖和受试者反馈进一步验证；
- 用统一的事件维度记录全局经历，而不是只放大某一件事件；
- 评估是否带来更好的作答体验，包括理解度、负担、完成率、顺序效应和数据完整性。

体育研究是该工具的一个应用场景。整体分析顺序为：先检验暴露与结局的关系，再探索自我调节、情绪调节、心理韧性、孤独感等核心量表的中介或调节作用。

## 当前研究问题

1. 新工具是否比 CTQ/ASLEC 类静态量表提供更完整的正负经历覆盖、时间轨迹和当前影响信息？
2. 新工具是否具有可接受的信度、效度、完成率和作答体验？
3. 在体育应用中，获奖经历和训练经历是否与心理韧性、焦虑和抑郁相关？
4. 自我调节、情绪调节、心理韧性、孤独感等变量是否解释或改变这些关联？

## 项目结构

- `docs/`：研究设计、变量字典和版本记录
- `questionnaire/`：问卷文案与跳转逻辑
- `analysis/`：分析计划、数据质控和结果模板
- `data/`：只放脱敏数据；原始个人信息不进入本项目
- `src/`：后续的数据处理和分析代码
- `reference_notes/`：对博导项目的学习笔记，不存放博导项目原始数据

## 与博导项目的字段边界

博导项目 README 中的 `F7` 是转折类型 `mid_kind`，不是社会生态。社会生态在博导项目中由 `where_eco`、`who_tie`、`closeness` 等字段共同表示。本项目将体育社会生态模块命名为 `SE1–SE7`，避免同名异义。

## 当前版本

- `v0.1`：基础版研究结构和 SE1–SE7 体育社会生态代码本
- 结果变量：心理韧性 + 焦虑/抑郁筛查
- 事件单位：比赛获奖事件、训练阶段、训练转折
- 基础设计：大学生横断面调查；后续可扩展为 T0/T1/T2 追踪

## 研究边界

横断面数据只能支持关联和可能机制的解释。只有在明确的时间顺序和追踪数据支持下，才使用“影响”或因果措辞。
