# 博导 README 学习笔记：构念与字段映射

## 先区分“项目说明”和“操作指令”

README 主要是测量结构、字段约定、假设和质控说明。附录中的 `open ...`、`python3 ...`、`Rscript ...` 是博导项目的开发预览命令，属于原项目操作说明，不是本项目必须执行的指令。本项目不直接运行这些命令，也不修改博导仓库。

## 博导项目的六个构念

1. 事件中心性：Q6 `centrality`
2. 可控感：Q3 映射为 `control_w`
3. 人际相关：Q2/Q7 映射为 `who_tie`、`closeness`
4. 转折点：Q4 映射为 `turn_w`、`ongoing`、`mid_kind`，必要时补 `age_mid`、`r_mid`
5. 客观常模严重度：清单隐藏的 `obj_raw`、`obj_w`
6. 影响轨迹：画树的 `r_then`、`r_now`、`age_*`、`path_ar`，以及 Q5 `now_salience`

## F0–F20 的关键含义

| 字段 | 含义 |
|---|---|
| F0 `where_eco` | 发生地点映射的生态情境码 |
| F1 `centrality` | 事件中心性 |
| F2 `control_w` | Q3 归因映射的可控性 |
| F3 `who_tie` | 关系纽带 |
| F4 `closeness` | 与关键人物的亲疏 |
| F5 `turn_w` | Q4 结果映射的转折强度 |
| F6 `ongoing` | 是否仍未解决/持续 |
| **F7 `mid_kind`** | **没有/变强/变弱/说不清的转折类型** |
| F8 `age_mid` | 条件转折年龄 |
| F9 `r_mid` | 条件转折时影响 |
| F10 `impact_delta` | `r_now - r_then` |
| F11–F12 | 客观事件严重度及归一化 |
| F13–F17 | 轨迹起止影响、年龄和当前显著性 |
| F18 | 角度 `theta` |
| F19 | `now_salience >= 0.7` 的当前焦点事件 |
| F20 | 影响变化方向 |

## 可迁移到体育项目的设计契约

- `select_order` 是时间顺序契约：选择顺序、画线顺序和详情顺序一致；
- `path_ar` 保存有符号的 `[age, r]` 轨迹，年龄非降，最多 32 个点；
- 起点锁在事件正负归属侧，跨过中线才硬写 Q4 的跨向结果；
- 不能仅凭 `r_then` 和 `r_now` 臆造中间转折年龄；
- 清单隐藏的 `obj_raw` 是研究者的客观锚，不是被试评分；自填事件默认 90 且不作高低锚；
- `Q5` 的当前影响与 `Q6` 的中心性分开，不能合成一个“影响分”；
- 工具可用性、练习失败、停留时间和努力程度用于质控，不直接作为心理结局。

## 对本项目的命名决定

本项目不使用“F7 社会生态”作为正式变量名。体育社会生态模块使用 `SE1–SE7`；如果后续需要与博导项目做映射，再建立单独的 crosswalk 表，不覆盖原项目 F7 的含义。
