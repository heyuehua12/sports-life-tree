# 分析计划 v0.1

## 主要暴露

- 获奖：最高层级、获奖次数、距最近一次时间、个人/团队、主观重要性
- 训练：训练年限、过去 3 个月每周频次、每次分钟数、连续性、训练中断
- SE1–SE7：教练/队友支持、关系质量、自主权、资源公平、控制感和后续轨迹

## 工具验证分析

- 与 CTQ/ASLEC 类静态经历指标比较内容覆盖：正向经历覆盖率、负向经历覆盖率、事件类型多样性、时间信息完整度和当前影响信息完整度。
- 比较新工具与静态量表在心理结局上的关联强度和增量解释量；不能只凭题目更多就宣称“更好”。
- 体验指标至少包括完成时间、完成率、退出率、理解/操作评分、主观负担和数据缺失率。
- 记录并检验 `select_order` 的首个回忆效应；首个回忆事件不自动视为最重要事件。
- 评价正负性完整性前，先通过专家评审、认知访谈和小样本开放式补充检查清单是否遗漏重要体育经历。

## 样本与分层

- 纳入：当前在读大学生；体育专业、校队/竞技训练身份均可重叠。
- 主编码：`pe_major`（体育专业=1/否=0）、`team_athlete`（校队/竞技训练=1/否=0）。
- 描述性展示可给出四个组合单元：两者均否、仅体育专业、仅校队/竞技训练、两者均是；主模型不把它们误当成互斥自然类别。
- 训练暴露、比赛经历和获奖经历分别测量，不能用“是否体育专业”替代训练量。

## 结局

- 心理韧性：CD-RISC-10 总分
- 焦虑/抑郁：PHQ-4 总分及两个分量表；正式研究版可分别使用 GAD-7 与 PHQ-9

## 协变量

年龄、性别、年级、睡眠、伤病、既往心理帮助、家庭社会经济状况和一般身体活动。

## 统计顺序

1. 完成率、逻辑冲突、异常时长和缺失模式
2. 描述统计和量表内部一致性
3. 韧性、焦虑和抑郁的主模型
4. 心理韧性间接效应
5. SE 支持、自主权和资源公平的交互作用
6. 事件嵌套于个体时使用混合效应模型
7. 预先指定主结局、主暴露、缺失处理和多重比较策略

横断面数据只报告关联；追踪数据再讨论时间顺序和影响。

## 横断面主模型

- 以 CD-RISC-10、PHQ-4/PHQ-9、GAD-7 分别作为连续结局，使用多元线性回归或广义线性模型。
- 主暴露分别放入训练年限/近期训练量、获奖层级/次数/最近性；不要先合成未经验证的体育经历总分。
- 控制年龄、性别、年级、睡眠、伤病、家庭社会经济状况和既往心理帮助。
- 探索交互：训练量 × `pe_major`、训练量 × `team_athlete`、训练环境支持 × 训练量。
- 心理韧性到焦虑/抑郁的间接效应采用 bootstrap，明确标注为横断面机制探索，不作因果结论。

## 中介与调节的顺序

第一步只检验获奖/训练暴露与心理结局的主关联；第二步再加入自我调节、情绪调节、心理韧性、孤独感等中介或调节变量。心理韧性不能在同一个模型中既被当作结局又被当作中介，角色需要按具体模型预先固定。
